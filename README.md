# 浏览器标签标题管家

**浏览器标签上的标题总是带一堆没用的东西？bangumi 收藏成书签，默认名却是一串日文？**

这个脚本统一接管标签标题，做两件事：

1. **通用清理** —— 去掉标题开头的未读计数（`(3条消息)`、`(1)`、`(12)`），只动开头那一段，标题中间和结尾的括号一律不碰
2. **bangumi 中文名** —— 在作品页、角色页把标签标题换成页面里已经写着的**中文名**，收藏成书签时的默认名就是中文

**安装** → <https://greasyfork.org/scripts/551523>（先装 Tampermonkey / Violentmonkey 等脚本管理器）

## 它改什么，不改什么

| 页面 | 标签标题（改前） | 标签标题（改后） |
| --- | --- | --- |
| bgm.tv/subject/8 作品页 | コードギアス 反逆のルルーシュR2｜Bangumi 番组计划 | **Code Geass 反叛的鲁路修R2** |
| bgm.tv/character/1 角色页 | ルルーシュ・ランペルージ｜Bangumi 番组计划 | **鲁路修·兰佩路基** |
| bgm.tv/subject/8/ep 章节页 | コードギアス 反逆のルルーシュR2 的章节列表 | 不动 |
| bgm.tv/anime 列表页 | 动画｜Bangumi 番组计划 | 不动 |

- **只改标签标题**（以及由此得来的书签默认名）。页面正文、图标、网址一个字都不动。
- 中文名只从页面里读：作品页读信息栏的「中文名」，角色页读「简体中文名」。**不联网、不调翻译 API、不猜。**
- 取不到中文名，或页面标题里找不到对应日文名时，**原样保留** —— 宁可少改，不要改错。
- 标题随时可能被网页自己改回去，脚本会一直守着，改回来。

## 安装

1. 装一个脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 打开 <https://greasyfork.org/scripts/551523>，点安装

## 常见问题

**bangumi 页面的标题没变中文？**
可能这条目的中文名没登记（信息栏里没有「中文名」那一行）；也可能页面标题用的是简称，与完整日文名对不上，这种情况按"宁可少改"跳过。

**想收藏某个作品为书签？**
直接 Ctrl+D 即可，脚本已经让标签显示中文名。

**和别的改标题的脚本一起用？**
别的脚本会和我们抢标题，标签可能来回闪。**同一时间只留一个改标题的脚本。**

**章节页为什么不管？**
单集书签很少用；曲线救国没意义，干脆不碰。

**和《网页标题标签智能清理器》是什么关系？**
本脚本是它的重写版（沿用同一个 GreasyFork 脚本页）。如果你从别的渠道装过旧版，请卸载旧版，两个都装会互相抢标题。
